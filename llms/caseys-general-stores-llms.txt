# Casey's General Stores

> Casey's General Stores (NASDAQ: CASY) is one of the largest convenience-store chains in the United States, operating more than 2,900 stores across the Midwest selling fuel, made-from-scratch pizza and prepared food. Casey's runs a B2B API estate on Azure API Management at `esl.caseys.io` covering stores, items, fuel prices, tax, tank telemetry, suppliers, in-store messaging and Conexxus POS document ingestion.

This file was generated by API Evangelist from Casey's own published contracts. Casey's does not publish an llms.txt of its own (`/llms.txt` returned 403 on caseys.com and 404 on developer.esl.caseys.io, probed 2026-09-05).

## Access
- Developer portal: https://developer.esl.caseys.io/ (sign-in required for everything except the home page)
- API gateway: https://esl.caseys.io/<api-path>
- UAT gateway: https://uat.esl.caseys.io — UAT portal: https://developer-uat.esl.caseys.io/
- Auth: Azure API Management subscription key, `Ocp-Apim-Subscription-Key` request header (or `subscription-key` query parameter). One key per API product; a key for one API does not authorise another.
- Pricing: none published. 23 APIM products, all "Default", all with an empty description and no quota.
- Rate limits: none documented and none observable on live responses.
- Idempotency: none. No write in this estate declares an Idempotency-Key header.
- Reversibility: none. There is no DELETE verb and no cancel/void/undo operation anywhere in the 158 published operations.

## APIs (21 current, 158 operations)
- [StoreApi](https://esl.caseys.io/storeapi): stores, hours, brands, amenities, locations and the division/region/district hierarchy. 37 operations; the v0 half is deprecated.
- [StoreDetailsApi](https://esl.caseys.io/storedetailsapi): the successor store-detail read surface. 23 operations.
- [OldStoreApi](https://esl.caseys.io/oldstoreapi): the legacy store surface. 28 operations, 12 deprecated.
- [ItemApi](https://esl.caseys.io/itemapi): Item Master (Pricebook) items per store, related items by UPC, plus a GraphQL endpoint.
- [FuelPriceApi](https://esl.caseys.io/fuelpriceapi): fuel prices for a list of store numbers.
- [TankLevelApi](https://esl.caseys.io/tanklevelapi): most recent fuel tank level readings; accepts new readings.
- [TaxApi](https://esl.caseys.io/taxapi): tax calculation plus per-store tax strategies, tax levels and compound taxes.
- [SupplierApi](https://esl.caseys.io/supplierapi): supplier list per store, plus a GraphQL endpoint.
- [ItsmApi](https://esl.caseys.io/itsmapi): create, update and attach files to IT service-management incidents.
- [StoreMessagingApi](https://esl.caseys.io/storemessagingapi): register store agents and send messages to in-store services.
- [StoreNumberApi](https://esl.caseys.io/storenumberapi): available store numbers and version/health.
- [CasApi](https://esl.caseys.io/casapi): POS Activity Report document storage — Conexxus POS Back Office Interface.
- [CasGatewayApi](https://esl.caseys.io/casgatewayapi): POSJournal document storage and retrieval — Conexxus POS Back Office Interface.
- [TeamMemberApi](https://esl.caseys.io/teammemberapi), [DevOpsMetricsApi](https://esl.caseys.io/devopsmetricsapi): heartbeat only in the published contract.
- GraphQL-fronted operational APIs: [ProductionPlannerApi](https://esl.caseys.io/productionplannerapi), [DigitalProductionPlannerApi](https://esl.caseys.io/digitalproductionplannerapi), [KitchenSupplyOrderingapi](https://esl.caseys.io/kitchensupplyorderingapi), [PowerInventoryApi](https://esl.caseys.io/powerinventoryapi), [ShelfLabelPrintApi](https://esl.caseys.io/shelflabelprintapi), [VendorCheckinApi](https://esl.caseys.io/vendorcheckinapi).

## Standards
- Conexxus POS Back Office Interface and Conexxus POS Activity Reporting API — declared by name in the CasApi and CasGatewayApi contracts; the API major version mirrors the standard's.
- Conexxus Open Retailing — `openretailing-organization-id` and `openretailing-store-location-id` are required headers on all 7 POS operations.
- OpenAPI 3.0.1 across all 21 documents, every operation carrying a unique operationId.
